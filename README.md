- [] 자동차 이름 입력 받기
  - 쉼표(,)를 기준으로 구분
- [] 이동 횟수 입력
<br />

- [] 입력받은 이름만큼 자동차 생성
- [] 입력받은 횟수만큼 각 자동차 이동 여부 결정

- [] 자동차 이름 유효성 검사
  - 5글자를 초과한 경우
- [] 이동 횟수 유효성 검사
  - 자연수가 아닌 경우
- [] 잘못된 값을 입력한 경우 "[ERROR]"로 시작하는 메시지를 가지는 예외를 발생 후 프로그램 종료
<br />

- [] 무작위 값 생성(0~9 사이)
<br />

- [] 무작위 값이 4 이상인 경우 자동차 이동
- [] 무작위 값이 4 미만인 경우 이동x
<br />

- [] 이동 횟수가 가장 많은 우승자 선정
- [] 우승자 출력
  - 두 명 이상일 경우 쉼표로 구분
